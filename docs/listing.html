매물 내용 붙여넣기

매물 화면의 글(주소·가격·면적이 들어 있는 부분)을 복사해 붙여넣으세요. 휴대폰에서도 됩니다.

"부지파인더로 보내기" 버튼 만들기 (PC)

  1. 크롬 즐겨찾기 막대가 안 보이면 Ctrl+Shift+B를 누릅니다.
  2. 아래 노란 버튼을 마우스로 끌어서 즐겨찾기 막대에 놓습니다.
  3. 네이버 부동산이나 디스코에서 매물 상세를 연 상태로 즐겨찾기의 그 버튼을 누르면 이 화면으로 정보가 넘어옵니다.
  4. 잘못 읽히면 매물 설명 부분을 마우스로 드래그해 선택한 뒤 버튼을 누르세요. 선택한 글만 읽습니다.

부지파인더로 보내기
