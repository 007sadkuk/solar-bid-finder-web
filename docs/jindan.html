내 땅, 태양광 되나요?

주소만 넣으면 규제, 진입로, 경사, 전력망 여유를 한 번에 확인해 드립니다. 결과는 공공 데이터를 바탕으로 한 1차 진단입니다.

시·군부터 번지까지 적어 주세요. 산에 있는 땅은 번지 앞에 '산'을 붙입니다.
  1. 1지적도에서 땅 찾기
  2. 2규제 확인 (개발제한·농업진흥·보전산지)
  3. 3진입로와 경사 확인
  4. 4전력망 여유와 예상 수익 계산
